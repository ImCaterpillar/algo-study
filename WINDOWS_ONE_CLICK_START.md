# Windows One-Click Start

Use the root-level script below:

```cmd
start-windows.cmd
```

Or double-click:

```text
start-windows.cmd
```

Chinese-named entry is also available:

```text
One-click file: 一键启动.cmd
```

Default npm registry:

```text
https://registry.npmmirror.com/
```

To use the official npm registry:

```cmd
start-windows.cmd https://registry.npmjs.org/
```

This version keeps PowerShell scripts ASCII-only to avoid Windows PowerShell encoding/parser issues.
